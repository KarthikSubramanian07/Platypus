How it works

Any agent asks. Platypus finds a route, or makes one.

  1. 01

    Ask

    Claude, or any agent that speaks MCP, sends the job to Platypus.

    request_booking

  2. 02

    Darwin first

    Darwin Search v3 looks for an agent that already does this job.

    Darwin: no agent can book it

  3. 03

    Call once

    Dial calls the shop. The AI says it is an AI, books through our tools mid-call, then asks:

    “Can I text you next time?”

  4. 04

    Text forever

    Every later request is a text, Dial to Dial today.

    New job: brake inspection, Tue 10am. Reply Y, N, or a time.

    Y

Confirmed means the owner said yes, on the call or by text.
